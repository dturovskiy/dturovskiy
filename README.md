### Deus AI Limits Extension

A Chrome toolbar extension for checking Codex and Claude usage limits from signed-in browser sessions.

- Local-first browser extension.
- No external backend.
- No analytics.
- Minimal Chrome permissions.
- Codex and Claude usage-limit views.
- Dark/light/system themes.

Repository: [`deus-ai-limits-extension`](https://github.com/dturovskiy/deus-ai-limits-extension)

### Deus Commit Chart

A reusable local Git commit activity chart generator.

- Generates a self-contained HTML chart.
- Works from any local Git repository.
- Designed for quick visual project history review.

Repository: [`deus-commit-chart`](https://github.com/dturovskiy/deus-commit-chart)
